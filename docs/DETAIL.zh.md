# AI 工具积分余额

一个可以拖动的小面板，把本机已连接的各家 AI 工具剩余积分放在一起。

## 位置与操作

- 默认是一条**紧凑的小长条**，落在窗口右侧（右侧栏那一块），每个工具一小段：`豆包 1,924 · 千问 2,100 · WorkBuddy 217.28 · Trae 900 · Qoder 800`，末尾是「⟳」和「详情」。
- 长条宽度固定在一个较小的上限（约 330px）：工具多了会自动换行变高，不会越拉越长。
- 点「详情」展开成一个**大一些的方框**，而且是**向上展开**：面板的右下角不动，方框从长条的位置往上长，不会把下面的内容顶下去。框里逐行列出余额、套餐/账号、每个额度包的「剩余 / 总量」以及到期或重置时间，还有合计；内容超出时框内滚动。框里的「收起」回到长条。
- **拖动**：按住长条（或方框标题栏）任意位置拖到别处；位置和展开状态会记住，重开页面还在原处。拖动只受窗口边界限制。位置按**右下角**记，所以收起 / 展开时同一个角保持不动。
- 面板只占自己那一小块，覆盖层本身是点击穿透的，所以不会挡住底下的界面。
- 「⟳」立即重读；平时每 60 秒自动刷新。

## 它读什么

这个面板**不登录任何账号，也不访问厂商接口**。它只读取已安装的连接器插件自己发布的只读本地路由：

| 工具 | 数据来源 |
| --- | --- |
| 豆包 | `GET /plugins/dsh-connect-doubao/quota` |
| 千问工作 | `GET /plugins/dsh-qwenwork-connect/status` |
| WorkBuddy | `GET /plugins/dsh-connect-workbuddy/usage` |
| Trae | `GET /plugins/dsh-connect-trae/usage` |
| Qoder | `GET /plugins/dsh-qoder-connect/status`（国内版未登录时自动试 `global/status`）|

没安装的连接器返回 404，对应项自动隐藏；未登录的连接器显示「未登录」，不会显示成 0。

## 关于合计

合计只出现在展开的方框里，是**当前已读到**工具剩余积分之和。不同工具的积分不能互换，它只用于快速比较总量；只要有工具没读到，合计前面会加 `≥` 并标注覆盖率（例如 `3/5`）。某个工具只是网络抖动时，面板会保留上一次的数值并标注「上次读取的值」。

## 界面语言

面板的中英文案跟随 DSH 当前界面语言，**在界面里切换语言会立即生效**，不用刷新页面。中文环境下显示「合计 / 详情 / 收起 / 积分」等中文，英文环境下显示对应英文。

## 已知限制

- 显示的是**连接器报告的数字**；连接器自己缓存的额度多久更新一次由它决定，本插件不触发上游刷新。
- 只支持上表这五个连接器。新增工具需要在本插件的 `client.js` 里加一条适配器。
- 面板位置记在浏览器的 localStorage 里，换端口或换浏览器不会带过去。

## 开发自检

改完 `client.js` 可以跑 `node tools/check.mjs`（需要 Harness 在跑）：它会读取真实连接器路由验证五个适配器，并用钩子脚本化的 React 桩渲染长条 / 方框 / 降级状态。
